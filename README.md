## 5. Key implementation choices (details and justification in the report)
* **Flow → 15 min:** the LargeST flow is a vehicle *count* per 5 min (all values are integers, 8.6 % divisible by 12) → **SUM** of 3 readings = vehicles per 15 min; NaN-aware (2/3 valid → ×3/2, ≤1/3 valid → missing).
* **Missing data:** NaN and ≥ 3 h runs of identical readings (sensor outage) are treated as missing; model inputs use causal forward-fill (≤ 1 h, inside each split) then the per-sensor *training* mean; loss and metrics use only observed targets.
* **Graph:** the provided road-distance adjacency is **directed** → fixed graph `D_out⁻¹(A+I)` (row-normalised). Adaptive graph `softmax(ReLU(E1E2ᵀ))`, own implementation, top-k = 20 selected *before* the softmax. Hybrid `αÂ_fixed + (1−α)A_adaptive` with learnable `α = σ(θ)`.
* **Normalisation:** per-sensor z-score from the training split only; the MAE loss is weighted so that it equals the raw-unit MAE.
* **Metrics:** MAE/RMSE in vehicles per 15 min, overall and per horizon (15/30/45/60 min), on observed targets only, identical for all models.
